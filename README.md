### Installation for linux

1. Clone the repository
```sh
git clone git@github.com:EpitechPGE3-2026/G-AIA-500-PAR-5-1-sensai-1.git
cd G-AIA-500-PAR-5-1-sensai-1.git
```

## Running the application

Install the project from its root first:

```sh
pip3 install .
```

### CLI

Start the CLI with a configuration file:

```sh
wu -c configs/cloud_config.yaml
```

### API

Start the API server with:

```sh
wu-api
```

The API is then available at <http://127.0.0.1:8084>.
